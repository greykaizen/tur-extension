# TUR Extension & Overlay

`tur-extension` (locally known as `tur-overlay`) is a core component of the TUR ecosystem. This project provides a browser extension and its associated native messaging host, bridging the gap between web experiences and native system capabilities.

As part of the **TUR Family** (alongside [tur-rs](https://github.com/tur-rs) and [tur-tauri](https://github.com/tur-tauri)), this project is built with Rust for high performance and reliability. It specifically focuses on delivering a robust overlay and extension system.

## Project Structure
- `extension/` - Browser extension source code
- `crates/host/` - The native messaging host implementation (`tur-native-host`)
- `crates/button/` - Overlay or button interactions library
